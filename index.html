      Connect to TMDB

      FlowingDaFilms gets its movie data from The Movie Database (TMDB). It needs a free TMDB API key to load movies.

      1. Create a free account at themoviedb.org.
      2. Go to Settings → API and request an API key (choose "Developer").
      3. Copy the API Key or the API Read Access Token and paste it below.

      A key saved here is stored only in this browser. To give every visitor real data, set TMDB_API_KEY at the top of script.js instead.
